# Produktivni.cz

Web o produktivitě — ověřené know-how, denní tipy a triky, AI novinky a školení pro firmy.

📋 **[Zadání projektu → ZADANI.md](./ZADANI.md)** (verze 1.0, čeká na schválení)

## Plánovaný stack

- **Next.js + TypeScript + Tailwind** — web (deploy na Vercel)
- **MDX v tomto repozitáři** — obsah (příručka, tipy, novinky)
- **Brevo** — newsletter a sběr kontaktů
- **Claude Code rutina** — automatický sběr novinek a návrhy obsahu přes PR
- **Gemini API** — generování vizuálů
- **Buffer** — distribuce na sociální sítě
