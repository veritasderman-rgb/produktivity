Podle dokumentace DuckDB je rozšíření pro čtení Excelu základní a při prvním použití se načte samo; ručně ho „doinstalovávat“ není potřeba. Čte se jen formát `.xlsx`, starší `.xls` ne. Návod jsme upravili: místo „po doinstalování rozšíření“ nově říká, že se rozšíření stáhne samo a poprvé je potřeba být online.

---EN---

According to the DuckDB documentation, the Excel extension is a core extension and loads itself on first use; no manual install is needed. Only `.xlsx` is supported, not the older `.xls`. We updated the guide: instead of "once you install an extension" it now says the extension downloads itself and you need to be online the first time.
