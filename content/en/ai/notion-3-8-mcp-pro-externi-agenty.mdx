**What happened:** On October 13, 2026, Notion released version 3.8, subtitled "Context for your agents". The headline change is that **any compatible AI agent** can now connect to Notion through MCP (Model Context Protocol), read your workspace context, and update docs and task databases. Workspace admins can see who connected which AI tool and when it was last used, and can **revoke one person's access** without breaking anyone else's connection. The release also adds version history for pages and databases (highlighted edits, database change details, attribution and one-click restore), per-column permissions in databases, and a Skills API that syncs skills from Notion to tools such as ChatGPT and Claude. Notion Agent and custom agents also gained 150+ tool connections (HubSpot, Stripe and Cloudflare, for example). Notion does not state plan availability for most of these items, so check it for your own workspace.

**What it means for you:** Notion shifts from a place where you store data to a shared memory for all your AI tools. You no longer paste context into a chat every time — the agent reads it itself. In practice:

- **Planning from one source** — in Claude you write "based on the project page in Notion, prepare the agenda for Thursday's meeting and add three follow-up tasks". The agent reads the page, proposes changes and writes them.
- **One set of procedures** — a skill your team uses in Notion Agent (say, "how we write the weekly report") can sync to other tools, so you don't write the procedure twice.
- **Control over what happened** — with version history and column permissions you can see what an agent changed and roll it back.

**How to start:**

1. In Notion, open the connection settings and link your AI assistant following the [Notion MCP help page](https://www.notion.com/help/notion-mcp).
2. Start with a single page or database the agent can access, and give it a read-only task — a project status summary, for example.
3. Once you're comfortable, allow writing and try a small edit, such as adding a due date to a task.
4. If you manage the workspace, go through the list of connected tools and disconnect the ones nobody uses.

**What to watch out for:** An agent with write access can change your team's documents. Give it access only to what it really needs, and use version history to review its changes. Connect only tools approved by your company to workspaces holding personal data or confidential contracts. The same principle applies as everywhere: AI proposes, a human approves the changes — especially in documents other people read.
