The fastest way to get to anything on Windows isn't the Start button — it's a launcher you open with a single shortcut from anywhere. PowerToys Run is a free module from Microsoft inspired by tools like Spotlight on the Mac — instead of clicking and searching an app list, you type a few letters and instantly have the program, file, or calculation result you need.

## A typical scenario

You need to quickly open the calculator, work out a price with VAT added, and then open a specific file you were just editing. Without a quick launcher, that means opening the Start menu, finding the calculator with the mouse or by typing its full name, calculating, closing it, and then browsing File Explorer to find the document you need among dozens of others. With PowerToys Run, you press the shortcut, type the math expression directly, and get the result without opening a calculator at all, and you find the file you need just as quickly by name.

## How to do it

1. Install **PowerToys** (a free set of tools from Microsoft) and enable the **PowerToys Run** module in its settings if it isn't already on.
2. Press <kbd>Alt</kbd> + <kbd>Space</kbd> anytime — a simple search bar appears on screen.
3. Type: an app name (and the program launches right away with the first <kbd>Enter</kbd>), a file or folder name (searches your system), or a math expression — say "2490*0.79" for a quick calculation.
4. PowerToys Run also handles unit conversions and other small calculations right in the bar, with no need to open a separate calculator.
5. Cycle through results with the up/down arrows and confirm with <kbd>Enter</kbd>; the first result offered is usually the one you're after.
6. PowerToys Run gradually remembers what you've searched for and launched before — frequently used apps work their way up to the top of the results over time, even before you finish typing the full name.

## The best tools

- **PowerToys Run** — free, from Microsoft, the fastest way to reach apps and files on Windows without touching the mouse.
- **The Start menu's built-in search** — works similarly, but is slower to open and offers fewer features (no calculations or unit conversions).
- **Wox** or **Flow Launcher** — free, open-source alternatives with similar functionality, plus extendable with plugins for specific work tools.

## What you get out of it

- **Time:** roughly 5 minutes a day saved on searching for apps and files you'd otherwise browse for with the mouse.
- **Smoother workflow:** you don't need to take your hands off the keyboard just to launch a program.
- **Less distraction:** a quick result without opening a separate calculator or browsing File Explorer means fewer chances to get sidetracked.
- **A habit that sticks:** once the shortcut becomes second nature, you reach for it even for small things you'd otherwise never bother opening a dedicated tool for.

## Pro tip

You can set a custom shortcut for PowerToys Run instead of the default one if <kbd>Alt</kbd> + <kbd>Space</kbd> conflicts with another program you use (some IDEs and graphics editors typically claim this combination too).
