Starting a new document is a small ceremony: open Google Drive, find the New button, pick a file type, wait. Yet there's a shortcut right in the browser's address bar: type **docs.new** and a new blank document just opens. Google and Microsoft have both built a whole family of these addresses — for spreadsheets, presentations, forms, and notes. It's the fastest way there is to start writing, calculating, or jotting something down.

## How to do it

1. Click into the address bar (fastest with the shortcut <kbd>Ctrl</kbd> + <kbd>L</kbd>), type the address, and press Enter:
   - **docs.new** — a new Google Doc, **sheets.new** — a new spreadsheet, **slides.new** — a new presentation, **forms.new** — a new form, **keep.new** — a new note
   - **cal.new** — a new event in Google Calendar, **meet.new** — an instant video call
2. You need to be signed in to your Google account; the file is created in your Drive as usual, and you can rename it or move it into a folder right away.
3. If you use Microsoft 365, the same thing works: **word.new**, **excel.new**, and **powerpoint.new** open a new file in the corresponding web app.
4. Your browser quickly learns these addresses — after a few uses, typing “do” is enough for it to suggest the full address.
5. If you have multiple Google accounts (work and personal), the file gets created in whichever one you're signed into first in the browser — check by clicking the avatar in the top right after the document opens, and either recreate it from the right account, or use a separate browser profile for each account.

## A typical scenario

Mid-call, you need to start typing minutes. The old way: a new tab, drive.google.com, waiting for Drive to load, the New button, Google Docs — ten-plus seconds, during which a colleague has already rattled off half the action items. With docs.new: a new tab, four letters, Enter, you're typing. Same with sheets.new when you want to quickly sketch out numbers during a meeting, or cal.new when the next meeting's time gets decided.

## What you get out of it

Going from “I need to write this down somewhere” to “already writing” takes one second. Sounds like a small thing, but exactly this kind of friction decides whether a note, a set of minutes, or a deadline actually gets recorded right away — or gets a “later” that never comes. Four letters in the address bar are faster than any bookmark you'd have to go find.

## Pro tip

A new document is nice, but a new document with structure is even better: right after opening docs.new, type [an @ sign and pick a template](/tipy/docs-zavinac-prvky) — say, meeting minutes with pre-built sections.
