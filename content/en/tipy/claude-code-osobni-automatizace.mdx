Most people know AI as a window in a browser: you paste something in, something comes out, you finish the rest by hand. Claude Code is a different category of tool — it runs on your machine, **it sees your files and can actually work with them**: read them, rename them, sort them into folders, write and run a script, open fifty documents and turn them into a single spreadsheet. The name invites you to file it under “for programmers.” In reality it's a general-purpose executor of multi-step tasks — exactly the kind you currently lose whole days to.

## A typical scenario

Hana, a bookkeeper, receives invoices from clients by email. In a month, one folder fills up with over four hundred PDFs named things like “scan_0042.pdf.” Before she can post them, she has to open each one, type the vendor, the amount, and the due date into a spreadsheet, and rename the file so it can be found again later. Two days every month, on repeat.

The second time around, she describes it in one paragraph: pull the vendor, amount, and date out of each PDF, rename the file following the pattern `2026-08-vendor-amount.pdf`, sort them into folders by month, and generate a single CSV with all the data alongside them. Claude Code writes a script, runs it on ten files first, and shows her the result. Hana fixes one rule (two vendors had the issue date mixed up with the due date) and lets it run through the rest. Review and wrap-up: under an hour. Next month she just repeats the same request.

A case study from a home kitchen: this website was built exactly this way. The articles, the English translations, and deploying new versions all go through Claude Code — the author writes the brief and approves the output, the tool does the work. It's exactly the fifth level from [the chapter on AI and automation](/prirucka/ai-a-automatizace): an agent that gets a goal and works through several steps to reach it, not a chatbot you carry data to by hand.

## How to do it

1. **Pick a task you do manually and repeatedly.** The best candidates share three traits: a lot of files, a clearly describable rule, and zero creative value. Sorting photos, renaming exports, pulling numbers off reports, bulk format conversion.
2. **Run the tool in the folder with your data.** Claude Code is controlled from the command line, and there's a web version too. It pulls context from whatever it finds in the folder — you don't have to upload things one by one.
3. **Write the brief like you're briefing a new colleague.** What's the input, what should come out, what should it be named, and what to do with exceptions. The most common cause of a bad result isn't a dumb AI — it's a brief missing a third of the information.
4. **A sample first, then the whole batch.** The sentence “try it on ten files and show me the result” is the cheapest insurance you have. A mistake on ten files costs a minute; a mistake on five hundred costs an evening.
5. **Have it save the rules to a file.** For recurring tasks, ask it to write up the procedure right in the project folder. Next time you just say “do it like last time” and don't have to remember exactly how it was specified.
6. **Back up before any bulk change.** A copy of the folder is enough. Anyone working with text or code should use git — then every step can be undone with a single command.

## The best tools

- **Claude Code** — works with files, runs scripts, and drives git; the pick for anything that needs to run on your own disk and has more than one step.
- **claude.ai** — chat, projects with persistent context, and artifacts (working mini-apps right in the window); for one-off things with nothing to install.
- **Git** — a safety net for bulk changes; not for everyone, but whoever has it sleeps easier.
- **Zapier, Make, or n8n** — when the task happens in the cloud between services rather than in files; covered in more depth in [your first no-code AI automation](/tipy/n8n-zapier-ai-automatizace).

## What you get out of it

- **Time:** a conservative one working day a month for anyone who regularly reshuffles files and retypes data from documents.
- **Peace of mind:** tedious work stops hanging over your head as the threat of a lost weekend. What's left is the decision-making nobody else can do for you anyway.
- **Quality:** a machine doesn't make a typo on line fifty because it's tired. It applies the rule the same way to the first file and the last.
- **Scope:** tasks you never even started before (“go through three years of statements”) suddenly fit into a single evening.

## Pro tip

Give the tool exactly as much room as it needs — not a foot more. Work in a copy of the folder, not the original, and keep file deletion for yourself. The same rule applies here as everywhere on this site: **AI proposes, a human approves.** And mind your data: send sensitive material (clients' personal data, finances, health records) only to a paid or business account with contractual data protection, never a free chat, and anonymize whatever can be anonymized beforehand. Once a quarter, check exactly which folders and services your automation actually has access to — permissions have a way of quietly piling up.
