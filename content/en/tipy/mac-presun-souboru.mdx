Unlike Windows, the Mac has no classic Ctrl+X for files — dragging files with the mouse between two open Finder windows is therefore slow and error-prone when moving between distant folders. Anyone switching from Windows finds this the most jarring difference, because the habit of pressing Ctrl+X runs deep. The solution is simple: copy the file as usual, and when pasting, add the Option key, which turns the copy into a move.

## A typical scenario

You have ten files in Downloads that belong in a project folder buried deep in your Documents structure. Dragging with the mouse would mean having both windows open side by side, aiming precisely at the target folder, and making sure the file doesn't accidentally get dropped somewhere else.

With Cmd+C and Cmd+Option+V, you copy the file, navigate to the destination folder, and paste — and the file disappears from the original folder, because it actually moved rather than being copied. So you don't have to go back afterward and manually delete a leftover copy that would otherwise sit around in Downloads.

## How to do it

1. Select the files you want to move and press <kbd>Cmd</kbd> + <kbd>C</kbd> — just as with a normal copy.
2. Navigate to the destination folder, either by clicking through, or faster with <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>G</kbd> and typing the path.
3. Press <kbd>Cmd</kbd> + <kbd>Option</kbd> + <kbd>V</kbd> — the files **move** to the destination folder; a plain <kbd>Cmd</kbd> + <kbd>V</kbd> would just copy them and leave a duplicate in the original folder.
4. If you accidentally move a file somewhere you didn't intend, the standard <kbd>Cmd</kbd> + <kbd>Z</kbd> will undo it.
5. It also works between your computer's drive and a connected external or network drive — a move between different volumes can take a bit longer, because the data is physically transferred, not just re-registered in the file system.
6. The move also works for multiple files and entire folders at once, so you can select a whole batch and move it in a single step.

## The best tools

- **The built-in Cmd+C and Cmd+Option+V combo** — the fastest route, nothing to install.
- **Dragging with the mouse while holding Cmd, between two Finder windows** — an alternative for when you have both destination folders visible side by side on screen.
- **Finder tabs (Cmd+T)** — open the source and destination folders as tabs in a single window and drag between them without switching windows.
- **Path Finder** — a third-party tool with an advanced file manager, for users who need more than standard Finder offers.
- **Holding Cmd while dragging with the mouse between volumes** — for moves between two different drives, a plain drag copies by default; holding Cmd turns it into a move.

## What you get out of it

- **Time:** moving from the keyboard is faster than precisely aiming for the destination folder with the mouse, especially when the source and destination folders are far apart in the tree.
- **Tidiness:** files don't end up duplicated in two places, as can happen if you forget to delete the copy after a manual copy-paste.
- **Less risk of error:** no dropping a file "next to" the destination folder, as easily happens when dragging with the mouse.
- **A tidier drive:** without forgotten duplicates in Downloads or on the Desktop, your storage doesn't fill up with unnecessary copies.

## Pro tip

The Cmd+C and Cmd+Option+V combo deserves a spot in your muscle memory right alongside regular copy and paste — once you've got it down, dragging files between windows with the mouse will start to feel needlessly slow.
