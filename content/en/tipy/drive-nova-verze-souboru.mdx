You send out a link to a PDF price list, and the next day you find a mistake. You fix it, upload the file again — except that creates a brand-new file with a brand-new link: "pricelist_final_v2_fixed.pdf." The old link keeps circulating out there, pointing at the wrong numbers. Google Drive has a little-known option for exactly this: **Manage versions**. A new file replaces the content of the old one, but the link, sharing settings, and location stay unchanged. Whoever had the link yesterday automatically sees the fix today.

## How to do it

1. In Google Drive, right-click the uploaded file (PDF, a Word document, an image, anything you've uploaded — this doesn't apply to native Docs and Sheets, which version themselves automatically).
2. Choose **Manage versions** (depending on your interface version, it may be directly in the menu).
3. Click **Upload new version** and pick the corrected file from your computer — the filename doesn't matter, versions are ordered by upload time.
4. Done: the same name, link, and sharing settings now point to the new content. Previous versions remain in that same dialog, downloadable, so you can revert or check what changed at any time.
5. Drive purges older versions after a while; mark any version you want to keep permanently with the **Keep forever** option in its menu.

If you use the Google Drive desktop app, it's even simpler: just overwrite the file on disk under the same name, and syncing saves it on Drive as a new version of the same file — link and sharing again stay put. Same principle, just without the manual upload.

## A typical scenario

A freelancer has shared a proposal PDF with a client; the link is already sitting in emails and the client's company chat. The client asks for a scope change. The old way, she'd send "proposal_v3.pdf" and hope everyone opens the right one. With version management, she uploads the fix under the same link — and it doesn't matter which email anyone opens the proposal from, every path leads to the current version. No need to forward anything to anyone or explain which attachment still applies.

## What you get out of it

An end to duplicate files named "final," "final2," and "final_actually," and an end to the uncertainty over who's looking at which version. One link is a document's permanent address — the content behind it evolves without you having to forward anything to anyone. And if a dispute ever does come up about what was in the document and when, older versions are right there to download and compare.

## Pro tip

For Google's native formats, [version history](/tipy/sheets-historie-verzi) does this job automatically. Manage versions is its counterpart for everything else just sitting on Drive — PDFs, Word attachments, images, archives.
