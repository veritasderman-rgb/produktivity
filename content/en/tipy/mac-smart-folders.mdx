Instead of running the same search over and over, save the search itself. Most people type the same query — recent invoices, fresh screenshots, documents edited this week — into Finder again and again, even though it can be set up once and left to keep itself current.

## A typical scenario

At the end of the month, a freelancer needs to go through every invoice they've issued or received for the period, wherever it happens to be stored on the drive — in Documents, in a downloaded email, on the Desktop. Without a smart folder, that means typing the search "invoice" all over again each time and sorting through the results by hand, because it's essentially the same search, just with a different date.

With a smart folder, the rule gets set once — file type PDF, name containing "invoice," last-modified date — and from then on all it takes is opening it. Finder always shows the current state of the drive inside it, with no need to run the same search again.

## How to do it

1. In Finder, choose **File → New Smart Folder** (or a keyboard shortcut, if you've assigned one in System Settings).
2. Use the **+** button in the top right to add one or more rules: file kind, creation or modification date, name, size, or even text contained inside.
3. Rules can be combined using the toggle at the top — "all" for the intersection of conditions, or "any" for broader results.
4. Results update live as you adjust the rules, so you immediately see how many files match.
5. Click **Save**, name the folder, and choose whether to also add it to the Finder sidebar for quick access.
6. From then on, the smart folder's contents update automatically — a new file that meets the conditions appears in it on its own, with no need to repeat the search.
7. A smart folder doesn't duplicate files or take up extra disk space — it's just a saved filter that displays links to the originals wherever they actually live.

## The best tools

- **Finder's built-in smart folders** — free, work instantly, and cover the vast majority of repeat searches.
- **Smart albums in Photos** — the same principle applied to photos, say "selfies from the last year" or "photos with a specific person."
- **Finder tags** — combined with color tags, a smart folder can filter by your own categorization too, not just system metadata.
- **Hazel** (paid tool) — for power users who want to not only search but also automatically move and rename files based on similar rules.

## What you get out of it

- **Time:** no more retyping the same search query — for recurring tasks like bookkeeping or cleanup, that's easily several minutes a week.
- **Visibility:** you always see the current state, with no risk of missing something because it's sitting in a different folder than where you last searched.
- **Less disk chaos:** you don't have to manually sort files into folders by type — a smart folder finds them wherever they are, while the original stays exactly where the system or app put it.
- **Consistent rules:** once a condition is set, it applies the same way every time, so results don't depend on remembering the exact right keywords each time you search.

## Pro tip

Great combinations to try: "recently opened documents" (a quick way back to work in progress), "screenshots older than a month" (for a regular desktop cleanup), or "invoices by filename" (at the end of every month, one glance tells you what to issue or what's still owed).
