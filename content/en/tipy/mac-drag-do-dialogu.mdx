The Save or Open dialog on a Mac is a small window with its own miniature navigation — and clicking your way deep into a project folder structure inside it is a hassle, especially when you already have the right folder open in Finder right next to it. There's a shortcut almost nobody knows: drag a folder from Finder (or from the desktop) straight into the open dialog. The dialog jumps to it instantly. No clicking through levels, no hunting in the sidebar. See it once, use it forever — and yet most longtime Mac power users have never heard of it.

## How to do it

1. Next time a Save (<kbd>Cmd</kbd> + <kbd>S</kbd>) or Open (<kbd>Cmd</kbd> + <kbd>O</kbd>) dialog pops up, leave it open.
2. Switch to Finder, find the destination folder, and drag it anywhere onto the dialog's surface — the dialog switches to it.
3. It also works with a file: dragging a file into the Open dialog selects that exact file; dragging one into the Save dialog jumps you to its folder — handy when you want to save a new file next to an existing one.
4. You can also drag the icon from another window's title bar, or an item from the Dock or the desktop — anything that represents a file or folder.
5. A related trick for the keyboard: even inside dialogs, <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>G</kbd> works for [jumping to a folder by typing its path](/tipy/mac-finder-go-to-folder), along with shortcuts like <kbd>Cmd</kbd> + <kbd>D</kbd> to jump to the desktop.
6. One more small thing that saves steps: the Save dialog has a small arrow to the right of the filename field — it expands the full view with a folder tree, sidebar, and a button to create a new folder if the destination doesn't exist yet.

## A typical scenario

An accountant downloads bank statements and files them into a structure: Clients → Smith → 2026 → Statements. But the Save dialog stubbornly remembers the last folder used for a different client, so every time it's the same routine: click through four levels, careful not to slip. Meanwhile she already has the Statements folder open in Finder, because she's checking what she's already downloaded there. Now she just drags the folder into the dialog — one second, the dialog lands in place, and the file drops exactly where it should. She uses the same move in reverse when opening files: a document that arrived by email gets dragged straight from the message window into the accounting program's Open dialog.

## What you get out of it

Saving into deep folder structures stops being a series of clicks and becomes a single drag. You'll feel it most with repeated saves into the same project folders, where you currently spend tens of seconds clicking around — several times a day, every day. And because the trick works in any app with standard dialogs, you learn it once and use it everywhere.
