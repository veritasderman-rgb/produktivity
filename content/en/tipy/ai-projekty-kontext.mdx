Explaining to AI, over and over, what you do, how you write, and who you work for is a waste of time — and that's exactly what projects are for. Both ChatGPT and Claude support a workspace with persistent instructions and uploaded files that remembers context across conversations, so you don't re-enter it for every new request, even when you come back after a week.

## A typical scenario

A freelancer writes a regular newsletter for three clients, and in every new AI conversation has to re-explain the style, tone, and structure each client prefers. Without projects: ten minutes copying old samples and explaining context before he even gets to the actual writing, and it triples for three clients. With a project set up for each client, he opens a conversation inside the “Newsletter — Client X” project, and AI already knows the style, the pricing, and the rules without him having to describe them again — writing can start right at the first sentence.

## How to do it

1. Set up a project with a clear name based on the topic or client — for example, “Newsletter” or “Client X.”
2. Upload materials you'll need repeatedly: a price list, sample texts in the required style, company guidelines.
3. Write persistent rules into the project instructions that would otherwise apply to every conversation — tone, output format, what AI should specifically avoid doing.
4. Start every new conversation on that topic inside the project, not outside it — otherwise the context is missing.
5. Update the materials in the project from time to time, so AI isn't working from outdated information.
6. If you work on several distinct projects or clients, set up a separate space for each — mixed context leads to AI confusing one client's rules with another's.

## The best tools

Any of these work on the same principle — context you set up once, which then automatically attaches to every new conversation.

- **Projects in ChatGPT** — a built-in feature with persistent instructions and uploaded files.
- **Projects in Claude** — a similar feature, which can additionally handle larger sets of documents at once.
- **A custom GPT with saved instructions** — for a repeated, narrow purpose, such as just reviewing contracts.
- **A shared folder of materials** (Google Drive, Notion) as the source you pull from and update the project's materials with.

The difference between a project and an ordinary conversation is mainly that you come back to it repeatedly, not just once.

## What you get out of it

- **Time:** no more re-explaining context — the conversation starts right at the request, not at the explanation.
- **Consistency:** output for the same client or project keeps the same tone and format regardless of who's running the conversation or when.
- **Sanity:** you don't have to remember what you told AI when — the rules are stored once and apply permanently.
- **Scalability:** a new team member gets up to speed on how to work with a client faster, because the rules are written into the project, not just in one person's head.

It's worth going through the project every so often to check that the instructions and materials still match how you currently work.

## Pro tip

Don't upload more sensitive data into a project's materials than strictly necessary — for client projects, consider anonymized samples instead of real contracts or personal data. An uploaded file stays in the project permanently, so decide up front what actually belongs there, and remove older materials you no longer need from the project.
