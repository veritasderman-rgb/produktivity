When something freezes, you don't want to go hunting for Task Manager. Most people reach for <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>Delete</kbd>, wait a moment for the blue screen with the menu, and only then click on Task Manager — all while the system is sluggish and nerves are frayed. There's a shorter path that skips that entire intermediate menu and takes you straight to the process causing trouble.

## A typical scenario

You're working in an app that suddenly stops responding — the window won't move, the cursor turns into an hourglass, and clicking gets you nowhere. Going through <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>Delete</kbd> opens a full-screen menu with lock, switch-user, and other options you have to click through before you even reach Task Manager. With <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>Esc</kbd>, Task Manager opens instantly, with no detour — you get to the frozen process a few seconds sooner and can end it without wading through a menu full of lock and switch-user options.

## How to do it

1. Press <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>Esc</kbd> — Task Manager opens directly, no intermediate screen.
2. In the process list, find the frozen app (usually labeled “Not responding”) and click to select it.
3. In the bottom-right corner (or the top bar, depending on your Windows version), choose **End task** — the app closes immediately, even if it refuses to close on its own, without needing to restart the whole computer.
4. If you're not sure which process the frozen app corresponds to, sort the list by CPU or memory usage by clicking the column header — the problem process is usually near the top.
5. On a Mac, the equivalent is <kbd>Cmd</kbd> + <kbd>Option</kbd> + <kbd>Esc</kbd>, which opens the Force Quit menu — the principle is the same, even though the menu looks different.

## The best tools

- **The built-in Task Manager (Ctrl+Shift+Esc)** — part of Windows, nothing to install, covers the vast majority of situations from a frozen app to checking overall system load.
- **Process Explorer (Sysinternals)** — a free tool from Microsoft with a more detailed view of processes, threads, and dependencies, useful for recurring issues.
- **Resource Monitor** (available right from Task Manager, on the Performance tab) — a more detailed view of disk, network, and memory load when you need to find the cause of a slowdown.
- **Force Quit on macOS (Cmd+Option+Esc)** — the equivalent built-in feature for Mac users, solving the same problem just as fast.

## What you get out of it

- **Time:** a few seconds faster access to a critical tool at the moment it matters most.
- **Peace of mind:** less fumbling and panicked clicking when the computer stops responding.
- **Fewer hard restarts:** quickly closing the one problem app is often enough, so you don't have to restart the whole system and lose work in progress in other programs.

## Pro tip

The **Startup** tab in Task Manager shows what launches automatically with the system, along with an estimated impact on boot time for each item. Turning off unnecessary apps (chat clients, update tools you don't need right away) speeds up your computer's startup without uninstalling anything. It's worth revisiting that same tab every few months, since new apps quietly add themselves to startup after installation without you noticing.
